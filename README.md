# 🌐 Personal Portfolio Website

Repository ini berisi source code website portofolio pribadi yang dibuat untuk menampilkan profil, keterampilan, pengalaman, dan proyek yang telah saya kerjakan di bidang teknologi informasi.

## 📌 Deskripsi

Website portofolio ini dikembangkan sebagai media untuk memperkenalkan diri secara profesional sekaligus mendokumentasikan perjalanan belajar, pengalaman, dan hasil proyek di bidang pengembangan web.

Melalui website ini, pengunjung dapat mengenal latar belakang, keterampilan teknis, pengalaman, serta proyek yang pernah saya kerjakan.

## ✨ Fitur

- **Home** — Halaman utama yang menampilkan perkenalan singkat.
- **About Me** — Informasi mengenai profil dan latar belakang.
- **Skills** — Daftar keterampilan dan teknologi yang dikuasai.
- **Projects** — Dokumentasi proyek yang telah dikerjakan.
- **Contact** — Informasi atau media untuk menghubungi saya.

## 🛠️ Teknologi yang Digunakan

- HTML
- CSS
- JavaScript

## 🚀 Cara Menjalankan Proyek
Your site is live at https://aziyah-pixel.github.io/portofolio/
